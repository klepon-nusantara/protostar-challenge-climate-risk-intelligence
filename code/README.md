# Code

Put the notebooks or scripts that produce `submission.csv` here, for example:

- `forecast.ipynb`: loads the training data, fits the model, writes `submission.csv`
- `requirements.txt`: the packages it needs

`check_submission.py` (from the template) checks `submission.csv` before you submit: `python code/check_submission.py`.

This dataset is a git repository, so you can push code like any other file. Replace this note with a short description of your files.
